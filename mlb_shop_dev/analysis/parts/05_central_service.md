# 중앙 집기·서비스·피팅룸 부속·모꾸존 분석

담당 범위: PDF p.059-082, p.096-098의 27페이지를 모두 원본 페이지 PNG로 시각 확인했다. 치수 단위는 mm다. 상세도 수량은 설치 평면의 추가 수량이 아니며, 사진은 해당 PDF에 수록된 참고사진이다. 독립 JPG는 사용하지 않았다. 공간 배치는 공간 담당자의 p.018 교차 확인 결과를 사용한다.

## 배치와 핵심 형상

p.018 기준 정문은 좌측 중앙, 중앙 집기군의 긴 축은 좌우 방향이다. HG A는 중앙군 좌상, B는 좌하, C는 우상, D는 우하에 대응하며 E는 내부 좌측, F는 내부 우측이다. A-D는 곡면 단부와 직선 모듈이 이어지는 집기군이다. 각 집기를 단순 직사각형 상자로 만들면 중앙 통로와 타원형에 가까운 전체 실루엣이 달라진다. 각 모듈의 국부 원점과 회전은 최종 p.018 평면에 맞춰야 한다. 서비스·카운터는 p.018 우상, 두 피팅룸은 우하이며, 내부 부속은 p.035-036 방 내부와 함께 배치한다.

도면상의 분홍·파랑·노랑은 분류 해치 또는 강조색이다. 실제 금속·무늬목 색은 마감표와 수록 사진을 함께 참조한다. 아래 ‘명시’는 도면 치수·주석, ‘관찰’은 형상 시각 확인, ‘제안’은 Three.js 구현 판단을 뜻한다.

## 모꾸존

DP-T2는 p.096 전체 평면·입면과 p.097 후속 단면·서랍·사진이 한 완제품을 설명한다. p.096의1 SET에 p.097을 더하지 않는다. 두 팔이120°로 꺾이는 비직교 카운터형 집기이며 각 팔 깊이600, H920, 정면 투영폭2120와 다른 방향 투영폭2163은 서로 다른 뷰다. 직사각형 폭으로 통일하지 않는다. 상판의 작은 패치 분류 격자, WD-01 서랍, 좌우/하단500레일, T8 저철분 유리 선반, MT-02 프레임, MT-01 타공판을 분리한다. 후면 수납문과 유리 선반3단은 p.097에서 확인한다.

DP-T3는 p.098에서 별도 집기로2 SET 표기다. 평면 가로890과 입면 가로1000이 충돌한다. 깊이800, 높이800이며 중앙 하중 분산 보강, 상부 열린칸250, 하부 수납530으로 구성된다. ‘모꾸존 기기2EA 적용’과 두 압착기 참고사진도 함께 있다. 집기2 SET와 장비2EA의1:1 배치 여부는 p.018과 장비 위치를 추가 대조해야 하며, 장비4대를 추론하지 않는다.

인접한 모꾸존 벽면 W04(p.088-095)는 벽집기 담당 범위다. [벽집기 보고서](04_wall_fixtures.md)의 폭2000·H2500 모체, 타공판·사인·조명·선반·후크와 DP-T2/T3를 함께 조합해야 전체 모꾸존이 완성된다. 벽면 집기의 수량은 이 보고서의 테이블 수량에 포함하지 않는다.

p.098 전기 주석은 고용량 모자 와펜 압착기에 멀티탭 사용 불가, 콘센트 각각 필요, 기존 콘센트 용량 확인 필요라고 명시한다. 수록 장비 표는120V/240V 및 ‘1KWH’로 기재되어 있으므로 소비전력1kW라고 임의 정정하지 않는다. 장비 크기66×38×60.1cm는 참고 장비 표 수치이며 집기 치수가 아니다. ‘3.12 설치 후 지속 진행’ 등 프로모션 메모는 도면의 당시 운영 참고사항이며 현재 운영 사실로 주장하지 않는다.

## Three.js 제작 위임 제안

- `CentralIsland` 아래 HG-A/B/C/D를 독립 배치하고 곡선 프레임, 직선 프레임, 타공판, 가동 행거, 목재선반, 선반LED, 거울을 재사용 부품으로 둔다. 기둥을 관통하는 형상은 실제 기둥 메시와 간섭 확인 후 배치한다.
- `SuspendedHG` E/F는 바닥 기준 설치높이와 천장 고정점을 분리한다. 두 모델을 하나의 높이 파라미터로 묶지 않는다. 바리솔 천장 메시는 재료 담당 천장 높이와 연결한다.
- `CounterGroup`은 외피, 내부 캐비닛, 연속 목재 띠, LED 홈, 유리상판, 가드, 배경 격자판, 서비스 집기를 별도 자식으로 둔다. 치수 충돌 해소 전 평면 정합을 완료했다고 표시하지 않는다.
- `FittingAccessories`는 좌/우 선반거울을 방향 파라미터로 만들고 문짝 경첩 피벗도 좌/우를 분리한다. 방 껍질은 공간 담당 p.035-036을 사용한다. 별도 F/R MR은 세 번째 거울 객체다.
- `Customization`은120° 평면의 DP-T2와 직육면체 DP-T3를 구분한다. 패치 칸은 인스턴스, 유리 선반은 얇은 투명체, 압착기는 독립 장비로 배치한다. 전원 요구는 제작 메타데이터에 남긴다.
- 근거리에서 장공 타공 실루엣과 금속 반사가 중요하다. 원거리에서는 알파 마스크/인스턴스 기반 LOD를 사용할 수 있다. 시공용 볼트·내부 레일은 선택적으로 단순화하되 외부 대각브래킷·손잡이·문 환기구·LED 홈은 보존한다.

## 치수·코드 충돌 및 미확인

1. 카운터 p.018 평면2600/깊이500과 p.069 외장3300×800은 큰 차이다. 상세의 외장과 목가구 차이(p.071 3250×750)만으로 설명되지 않는다. 현장 상태/개정 관계 확인 전 양쪽 원문을 유지한다.

3. DP-T3 p.098 폭890/1000 충돌과 집기·장비 각2의 관계를 확인한다.
