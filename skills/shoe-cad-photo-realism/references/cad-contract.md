# CAD 분석 계약

CAD 원본을 직접 읽고 OCR은 보조로만 사용한다. 확대/크롭은 숫자가 읽힌다는 보장이 아니다. 작은 도면의 라벨·소재명·리더선 끝점·치수 화살표를 따로 확인한다.

## 기록 구조

다음은 필드 계약이다. 확인되지 않은 값은 null과 이유를 기록하며 예시 숫자를 채우지 않는다.

| 묶음 | 필드 |
|---|---|
| document | 원본 경로, SHA256, width/height, 문서 종류, 날짜/리비전 |
| identity | 브랜드, 스타일, 색상, 팀/로고, 시즌, 샘플 사이즈, last/outsole 번호 |
| materials | ID, 원문, 해석, 적용 영역, 색상, 두께/단위, 리더 끝점, 확신도 |
| dimensions | 원문 값/단위, 화살표 시작/끝 픽셀, 대상, 해석, 모호함 |
| boundaries | ID, 부품 A/B, 종류, 원본 픽셀 경로, 열린/닫힌 선, 근거, 오차 범위 |
| sockliners | 각 윤곽, 좌표·방향, 폭/길이 비율, 비대칭, 축척 유무, 라벨 영역 |
| discrepancies | CAD 주장, 실제 사진 관찰, 각 근거 위치, 선택한 목표와 이유 |
| assumptions | 사진/치수 미확보 항목, 사용자가 허용한 추정 범위, 적용한 가정 |

사진 목록은 각 이미지의 출처·각도·원본 크기·해시·정확한 제품 일치 근거를 포함한다. 시점 확보 표에는 required view, source IDs, 가림/부분 여부, missing 이유를 기록한다. 같은 사진의 상세 크롭을 별도 시점 확보로 집계하지 않는다.

## 선 분류

- `seam`: 실제 바느질 경로. 재단 경계와 항상 같은 것은 아니다.
- `material-boundary`: 다른 소재 또는 패널이 만나는 경계.
- `silhouette`: 그 시점에서 보이는 물체 외곽. 실제 절개선으로 새기지 않는다.
- `occlusion`: 다른 부위가 가린 경계. 숨은 끝점은 추정임을 표시한다.
- `decoration`: 자수·인쇄·디보싱·로고. 중복 형상/중복 글자로 만들지 않는다.
- `leader`: 사양을 가리키는 CAD 지시선. 제품 봉제선이 아니다.

원본 좌표와 분석본의 축척/크롭 오프셋을 보존한다. 경로와 리더 끝점이 이미지 범위 안인지 검사한다. 보조 오버레이에는 위 분류를 구분한 범례를 넣는다.

## 치수와 깔창 해석

샘플 사이즈, 라스트 번호, 모델 번호는 형상 길이 측정값이 아니다. 아이렛의 8mm 같은 표기도 내경인지 외경인지 화살표/사양에 없으면 단정하지 않는다. 지그재그 그림의 간격은 반주기/전주기 해석이 불확실할 수 있다. 문구와 실제 확인 수준을 함께 남긴다.

CAD 하단 작은 인솔 도식은 제거된 깔창, 안쪽 바닥, 아웃솔 중 무엇인지 문구와 형태로 확인한다. 한 쌍의 윤곽이 반대 비대칭을 가지더라도 관찰 방향이 불명확하면 임의로 좌/우를 확정하지 않는다. 앞코 폭·좁은 뒤꿈치·허리 굴곡은 내부 평면 형태의 참고이고, 외부 밑창 두께·트레드·실제 아치 높이를 제공하지 않는다.

인솔 프린트와 윤곽은 별개의 정보다. CAD와 생산 사진의 프린트가 다르면 실제 상품 재현에는 확인된 사진을 사용하고 충돌표에 남긴다. 미니어처 라벨 사각형을 구멍이나 형상 절개로 오인하지 않는다.
