# 사진·형상 접합에서 확인할 것

## 서로 다른 사진의 등록

측면별 높이 기준이나 원근이 다르면 같은 물리 구멍의 높이가 달라진다. 끈만 낮춰 맞추면 아이스테이에 높은 벽이 생긴다. 공통 라스트/경계에서 사진 등록을 먼저 확인하고 갑피·혀·구멍이 같은 보정을 소비하게 한다. 한쪽이 항상 정답이라는 가정도 근거가 필요하다.

등록 변형은 고무 경계와 확정 앵커를 보존하며 매끄럽게 감쇠시킨다. 인접 면 간 간격, 실제 삼각분할, 뒤집힘/음수 Jacobian을 확인한다. 특정 사례의 보정 상수를 다른 SKU에 적용하지 않는다.

## 끈과 중앙 고리

1. 구멍을 앞에서 뒤로 좌/우 ID로 지정하고 각 끈의 양 끝·보이는 중심선·위/아래 교차를 기록한다. 보이지 않는 삽입은 추정으로 구분한다.
2. 다른 구멍으로 연결할 때 내부 제어점도 새 끝점 기준으로 등록한다. 끝점만 바꾸고 예전 U자 내부점을 남기면 갈고리 모양이 된다.
3. 닫힌 타원 등 실제 단면을 유지하고 삼각형 winding/바깥 법선을 검사한다. 폭·두께가 정상이어도 면이 안쪽으로 향하면 띠 내부만 보일 수 있다.
4. 묶인 혀는 구멍 높이 아래에서 완만하게 지지하고 자유로운 혀 끝은 분리한다. 높은 혀를 그대로 두고 끈을 들어 올려 관통을 피하지 않는다.
5. 끈이 사라지면 실제 장면 raycast로 혀 관통, 다른 끈 가림, 고리 통과를 구분한다. 분석 수식의 간격뿐 아니라 실제 삼각형 교차를 검사한다.
6. 고리는 사진의 짧은 스트랩과 아랫단 봉제를 보존한다. 패치 전체 이미지는 한 번 매핑하고 결 타일처럼 반복하지 않는다. 끈을 덮는 부분과 혀 부착 끝을 함께 확인한다.

## 패딩과 안감

둥근 테두리 아래 평평한 벽을 붙이면 딱딱한 띠가 된다. 내부로 내려가는 단면을 연속 곡면으로 만들고 위치·접선·법선을 맞춘다. 보이는 패딩 볼륨을 반영하되 숨은 임의 굴곡을 덧붙이지 않는다.

곡선의 제어점 간격이 불균일하면 매개변수 t와 실제 거리 비율이 다르다. 조직 밀도를 실제 거리로 정할 때는 호길이 샘플과 UV도 같은 기준으로 만든다. 크롭 접합은 톤·물리적 조직 크기·UV 위상을 모두 검사한다. 상단 안감까지 같은 조직을 연속시킨 뒤 깊은 부위에서 다른 크롭으로 전환할 수 있다.

## 사진 소재 보정

원본 크롭에도 그림자·밝기 기울기가 들어 있으면 반복 띠가 된다. 먼저 더 적절한 크롭을 찾는다. 필요하면 같은 카메라에서 map 제거/무조명 map/원상복구를 비교해 형상·조명·이미지 반복을 구분한다.

진단 결과 저주파 밝기 기울기가 원인이면 별도 파생 이미지에서 기울기만 제거하고 평균과 실 조직 잔차를 보존할 수 있다. 채널별 식·계수·원본/결과 해시를 기록한다. 재질 외관 보정이지 측정 albedo 복원이 아니다. 실제 직조 주기와 잘못 반복된 조명 띠를 구분해서 본다.

고무 사진의 톤 이음은 공통 경계 주변에 한정해 맞춘다. 로고·트레드 원본 픽셀을 보호하고 형상 변경과 색 보정을 분리해 검증한다. 텍스처 혼합으로 실제 틈을 덮지 않는다.

## 작은 틈의 진단

정확한 캔버스 위치·DPR·카메라에서 화면 픽셀 중심을 raycast한다. 정수 좌표의 모서리 ray는 서브픽셀 틈을 놓칠 수 있다. 첫 hit가 가까운 갑피가 아니라 반대쪽 밑창이면 먼 고무 색이 틈으로 보이는 것일 수 있다. source 좌표와 공유 경계의 차이를 수정하고 동일 ray를 재검사한다.

최종 조립 상태에서 검사하고 국소 분리는 진단용으로만 사용한다. 도구 호출 실패나 부분 캡처는 제품 결함과 분리한다. 여러 브라우저 진단이 영향을 주면 캡처 소유자를 정해 순차 실행하고 자신이 연 브라우저만 닫는다.
