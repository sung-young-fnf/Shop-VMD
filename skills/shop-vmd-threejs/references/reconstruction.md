# 매장 자료 분석과 공간 재구성

## 근거의 우선순위

도면은 치수·인접 관계, 입면·단면은 높이·레벨, 실내외 사진은 형태·재료·분위기, 집기 상세는 독립된 구조, VMD 배치안은 배치 의도의 근거로 쓴다. 설계안과 현황 사진이 충돌하면 날짜와 용도를 구분해 어떤 상태를 구현하는지 기록한다. 파일명의 front/left를 실제 방향으로 무조건 믿지 않는다.

각 이미지에서 주요 구조 → 집기군 → 상세를 분해하고 연결·접촉 관계를 적는다. `path`, `role`, `width`, `height`, `sha256`, 확인 가능한 특징, 가려진 부분, 신뢰 수준을 기록한다. OCR 결과만으로 방이나 집기의 치수를 확정하지 않는다. 쇼핑몰 실내 매장처럼 외관 자료가 없는 대상에 외관 사진을 필수로 요구하지 않는다.

주택 구현에서 2550px 원본이 이미지 도구에서는 2048px로 보였다. 화면에서 읽은 픽셀을 원본 좌표로 사용할 때는 `native / displayed` 비율을 먼저 적용한다. 120×80px 입면도는 실루엣 참고는 가능했지만 창살이나 치수 측정 근거가 아니었다.

## 좌표와 치수

프로젝트 길이 단위는 하나로 통일하고 변환을 경계에서 처리한다. Three.js는 Y-up, 도면 평면은 XZ로 두는 구성이 편리하다. 예를 들어 `x=(u-u0)/scaleX`, `z=(v-v0)/scaleZ`로 변환하되 도면의 회전·왜곡이 있으면 먼저 바로잡거나 일반 변환을 명시한다. 출입구 방향과 도면 북쪽은 별개의 개념이다.

가로와 세로의 읽을 수 있는 치수를 각각 보정에 사용하고 긴 외곽 치수로 재확인한다. 내측 유효 치수와 벽체 포함 치수를 구분한다. mm→m는 1000으로 나누고, 피트·인치는 `(feet + inches/12) * 0.3048`로 환산한다. 알려진 치수가 없으면 상대 비율 모델로 표시하며 임의의 문 폭을 실측값으로 단정하지 않는다.

층의 높이는 마감 바닥, 슬래브 윗면·아랫면, 천장 마감 중 어느 기준인지 명시한다. 메시 중심 높이와 바닥 높이를 같은 값으로 비교하지 않는다. 도면으로 확정되지 않은 슬래브 두께는 추정 상태를 유지하고 `아랫면 + 두께 = 윗면`을 검사한다.

## 의미가 있는 모델 구조

다음은 필요한 부분만 사용하는 예시다.

```text
store
├─ shell: slab / walls / columns / openings / ceiling
├─ zones: entrance / display / sales / fitting / checkout / stock
├─ fixtures: rack-01 / table-01 / shelf-01 / mannequin-01
├─ merchandise: placement instances grouped by fixture
├─ signage: window graphics / POP / wayfinding
└─ lighting: tracks / fixtures / actual light sources
```

집기의 공통 형상·재질과 인스턴스의 위치·회전·크기를 나눈다. UI와 3D 선택, 사양과 QA가 같은 식별자를 사용해야 한다. 인스턴싱한 집기는 `instanceId`와 실제 `fixtureId`의 매핑을 유지한다. 실제 상품 자료가 없으면 중립적인 대체 형상으로 표시하고 제품 재현으로 주장하지 않는다.

집기 카탈로그의 분류와 물리적 배치 구역이 다를 수 있다. 의류 계열 벽 집기가 커스터마이징 코너의 배경으로 쓰이면 분류와 실제 `zoneId`를 분리한다. 기존 런타임 이름과 도면 품번이 다를 때는 명시적 별칭으로 연결하고, 품번·출처 페이지·구역이 같은 인스턴스를 가리키는지 검사한다.

## 형상과 접합

벽의 출입구·쇼윈도는 기둥 구간, 하부, 인방으로 분할하거나 구멍이 있는 프로파일로 만든다. 불투명 벽에 유리 면만 덧붙이면 내부에서 벽이 보이는 오류가 난다. 슬래브·벽·천장·사인 프레임이 만나는 면의 높이와 끝점을 공유하고, 겹친 표면의 깜박임을 확인한다.

주택의 포치 지붕은 사각 면을 겹쳤을 때 내부 마감선이 교차했다. 모서리를 맞춘 다각형과 외부 노출 변에만 적용한 마감으로 해결했다. 이 교훈은 매장의 캐노피, 천장 단차, 코너 사인·프레임 접합에 적용한다. 모든 매장에 박공지붕을 생성하라는 뜻은 아니다.

정면 렌더만 보면 뒤쪽의 누락된 면이나 부유하는 집기를 발견하지 못한다. 매장 둘레와 내부 진열대 뒷면도 확인한다. 면의 winding/normal을 고치지 않고 DoubleSide로만 가리는 수정을 피한다.

## 재질과 진열

재질은 baseColor, roughness, metalness, 투명도, 표면 요철을 분리해 정한다. 빛나는 플라스틱을 금속으로 처리하지 않는다. 조명이 들어간 사진의 하이라이트와 그림자를 albedo에 그대로 복사하지 않는다. 유리는 반사만 강하게 주어 내부를 완전히 가리지 않도록 실제 시점에서 확인한다.

브랜드 사인·패턴은 제공되거나 사용 가능한 에셋과 근거를 사용한다. 사진 투영이 필요하면 해당 면의 영역·원근·조명 보정과 UV 방향을 먼저 확인한다. 장면 전체 사진을 모든 벽의 재질로 덮지 않는다.

선반에 놓인 상품, 행거의 의류, 테이블 위 소품은 해당 집기의 로컬 좌표와 지지면을 기준으로 둔다. 상품이 떠 있거나 선반 안으로 파고들지 않는지 확인한다. 선반 단수·상품 수량·정면 방향은 자료가 있는 경우에만 일치 여부를 주장한다.
