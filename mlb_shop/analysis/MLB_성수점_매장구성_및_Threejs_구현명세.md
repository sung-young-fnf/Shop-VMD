## 1. 이 매장은 어떻게 구성되어 있는가

1층은 중앙에 네 개의 큰 곡선 진열 집기가 배치되어 육상 트랙 같은 긴 타원 윤곽을 만들고, 그 주위를 벽면 신발·모자·의류 집기와 서비스 공간이 둘러싼 매장이다. 정문은 기준 평면의 **왼쪽 중앙**, 카운터는 **오른쪽 위**, 피팅룸 2개는 **오른쪽 아래**, 모꾸존은 **왼쪽 아래**에 있다. 계단·화장실 코어는 위쪽 왼편, 리프트는 위쪽 오른편이다. 이는 PDF p018의 상하좌우 기준이며 지리적 동서남북을 뜻하지 않는다. [전체 평면 p018](../reference/drawing_captures/pages/page-018.png)

외관은 1층 유리 출입구·쇼윈도와 블루 포인트, 상부 2·3층의 반복 금속 루버/메시 입면, 수평 띠와 조명, MLB 로고, 측면 대형 이미지 배너로 구성된다. 공사 중 가림막은 최종 외관과 분리해야 한다. [정면 p008](../reference/drawing_captures/pages/page-008.png), [측면 p012](../reference/drawing_captures/pages/page-012.png), [출입구 p017](../reference/drawing_captures/pages/page-017.png)

2·3층은 판매 공간이라고 단정할 근거가 없다. 제공 도면은 상층 냉방 계획과 2층 창고 앵글장 배치를 중심으로 한다. 따라서 1층 판매장과 외관을 먼저 재구성하고, 상층은 창고·사무/휴게·코어 중심의 별도 구현 범위로 다루는 것이 적절하다. ## 2. 공간을 읽는 지도

아래는 위치 관계만 나타낸 도식이다. 실제 크기·동선 폭·벽 형상은 p018 원본을 따른다.

```text
                         p018 상단 / A면
             계단·화장실      모자 벽면      카운터·백월   리프트
          ┌──────────────────────────────────────────┐
          │ 체인 DP     HG-A ─────── HG-C             │
정면/     │                                          │ 신발·모자
D면 정문 →│            중앙 행거 E/F                 │ 벽면 / B면
          │            HG-B ─────── HG-D             │
          │ 모꾸존   의류·선반·거울·스툴              │ 피팅룸 1
          │                                          │ 피팅룸 2
          └──────────────────────────────────────────┘
                         p018 하단 / C면
```

정문을 통과하면 중앙의 곡선 진열대가 시야를 형성한다. 중앙 바깥과 안쪽 통로를 이용해 진열대를 살피고, 주변 벽면 상품 진열과 오른쪽 위 계산대로 연결된다. 이는 도형에서 읽은 이동 관계이며, 도면이 방문객의 고정 이동 순서를 지정한 것은 아니다. 입면 C는 보는 방향에 따라 평면의 좌우가 반전되므로 정면 그림을 그대로 배치하지 않는다. [공간 상세 보고서](parts/02_spatial.md)

## 4. 형상·재질의 핵심

### 외관

전체 입면 외곽 돌출부 폭17,035mm와 주 입면 폭15,935mm는 기준이 다르다. p008 높이9,700mm는 해당 입면 치수이며 전체 건물의 모든 상부 구조 높이로 확대 해석하지 않는다. p009 루버 구간 폭15,910mm, p011 철골 치수도 별도 기준이다. 정문은 p018의 왼쪽이므로 3D 외관 정면과 실내 평면의 축 변환을 먼저 합의한다. [외관 치수/접합/충돌 목록](parts/01_facade.md)

### 집기

중앙 HG-A/B는 상세도 폭4000, HG-C/D는 폭5240, 곡선 평면 깊이1520, 높이2480mm로 읽힌다. B/D에는 거울 끝부분 등의 변형이 있어 한 집기를 단순 복사만 해서는 안 된다. HG-E의 바닥 이격745mm와 HG-F의1700mm는 서로 다른 설치 조건이다. [p059–065 상세 분석](parts/05_central_service.md)

벽면 SH 5세트와 CA 8세트에는 하부장이 포함된다. 하부장·조명·백판·문 상세도는 부모 집기의 제작 부품이므로 별도 완제품으로 더하지 않는다. 일반 ML-W-04 3세트, 타공판 변형1세트, 2000폭 변형1세트를 구별한다. p093 소도구는 짧은 훅10개와 긴 훅10개의 두 변형이다. 전체 자산 목록과 설치 개수는 [벽면 집기 보고서](parts/04_wall_fixtures.md)에서 배치/상세 근거를 대조한다.

### 재질과 빛

회색 분체/발색 금속, 타공판과 메시, 블루 포인트, 무늬목, 콘크리트 계열 도장, 거울/아크릴, 패브릭을 분리해야 한다. 노란 해치가 항상 노란 재료를 뜻하는 것이 아니라 조명이나 목재 표기일 수 있다. 원본 재료표의 중복 코드 문제는 다음 절에 보존한다. [재료표 p003–007 및 적용표](parts/03_materials.md)

조명은 p026의4000K 기구와 p025 바리솔5000K처럼 계통별로 다르다. 다만 동일 외부 로고는 p017의5000K와 p010/p101의3000K가 충돌하므로 p101 값만 최종 사실로 채택해서는 안 된다. 외부 L-06과 일부 집기에도 색온도 충돌이 있다. 기구 재질의 발광과 공간 조도를 구분해 구현하고, 미확정 색온도를 변경 가능한 값으로 남긴다. 모든 기구를 그림자 생성 광원으로 만들 필요는 없지만 실물 위치와 발광 면은 유지하는 것이 구현 제안이다. [재료·조명 보고서](parts/03_materials.md)

### 상층 수납

2층 앵글장은1200×450×1800mm, 4단 구성이다. p105 반복 배치와 p106 수량 주석은 앵글106조·선반424개·기둥272개 **신규**를 나타낸다. 기둥 공유/연결 방식은 추가 확인이 필요하므로 독립 랙106개에 기둥4개씩을 자동 배정하지 않는다. 철제 옷장은 W900 D510 H1790, 6인용2단 제품2개다. [상층 상세와 수량 근거](parts/06_upper_boh.md)

## 6. Three.js 제작 위임 계약 (구현 제안)

단위는 도면mm를 보존한 사양에서 코드의m로 한 번 변환한다. 기준 평면 p018에서 오른쪽을 +X, 위쪽을 -Z, 높이를 +Y로 삼는 방식을 제안한다. 원점은 정해진 벽 기준 교차점에 놓고 모든 담당이 같은 기준을 사용해야 한다. 이는 도면에 있는 세계좌표가 아니라 후속 구현을 위한 계약이다.

```text
StoreRoot
├─ Exterior: facade / entrance / sideBanner / signage
├─ Floor1Shell: slab / walls / columns / beams / core
├─ CentralFixtures: HG_A / HG_B / HG_C / HG_D / HG_E / HG_F
├─ WallFixtures: ML_W01 / ML_W02 / ML_W03 / ML_W04 / ML_W05
├─ Service: counter / backwall / serviceTable / customization
├─ FittingRooms: room1 / room2 / sharedAccessoryDefinitions
├─ CeilingSystems: barrisol / tracks / lights / HVAC / CCTV / speakers
└─ UpperFloors: floor2Storage / floor3KnownLayout
```

| 제작 순서 | 담당과 산출물 | 의존성/확인 |
|---|---|---|
| 1 | 골조·정문·주요 벽·기둥·코어의 저밀도 공간 모델 | p018 및 입면 축 정합, 외관/내부 연결 확인 |
| 2 | 중앙 곡선 집기와 주변 벽면 집기 라이브러리 | 공통 좌표/단위 확정, 가족별 실루엣·완제품 수량 확인 |
| 3 | 카운터·모꾸존·피팅룸·문/거울 | 상충 치수의 채택 가정 필요, 동선과 문 여닫이 확인 |
| 4 | 재료 토큰·천장·조명·외관 세부 | 코드 중복 해결, 보/바리솔 간섭과 사진 기반 재질 대조 |
| 5 | 상층 창고와 부속 공간 | 구현 대상 층 선택, 도면이 제공하는 수준만 제작 |
| 6 | 존/집기 선택·평면/절개·실내/외 시점 | 사용자가 구현을 요청할 때 적용할 UI 제안, 아직 구현한 기능 아님 |

타공판·메시·루버·창고 선반은 반복 부품이므로 인스턴싱/LOD 후보이다. 근접 시 보이는 실루엣과 구멍·두께는 보존하고, 비가시 내부 체결부는 단순화할 수 있다. 이는 구현 최적화 제안이며 원본의 시공 정보를 삭제하라는 의미가 아니다.

후속 제작자는 공통으로 p018과 담당 보고서, 담당 캡처 manifest, 재료 보고서를 받아야 한다. 특정 확대 이미지만 주면 그 집기가 어디에 설치되는지 놓치기 쉽다. [캡처와 위임 사용법](../reference/drawing_captures/README.md)
